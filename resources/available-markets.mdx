The reference is organized two ways: by asset class and by execution venue. The tables below show only the go-live pairs. If a pair exists in internal tooling but isn't listed here, treat it as outside the launch set.

| Venue  | Main coverage                                              |
| ------ | --------------------------------------------------------- |
| GMX    | Crypto and commodities                                    |
| Ostium | Stocks, ETFs, commodities, indices, currencies, and selected crypto |

**Available on both venues at launch:** ADA/USD, BNB/USD, BTC/USD, CVX/USD, ETH/USD, HYPE/USD, LINK/USD, SOL/USD, TRX/USD, XRP/USD.

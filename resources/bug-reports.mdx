Found an issue? Report it through the official path with enough detail to reproduce. Valid reports may be rewarded with **DojiPoints** and additional ecosystem incentives.

## How to report a bug

<Steps>
  <Step title="Join the official Discord">
    Access the support and ticket channels.
  </Step>

  <Step title="Verify your account">
    Unlock the ticket channels.
  </Step>

  <Step title="Open a support ticket">
    In the tickets channel, select the category that matches your issue.
  </Step>
</Steps>

<Warning>
  Scammers impersonate moderators and support staff. Never share wallet keys or passwords, never trust unsolicited DMs, and never send funds to anyone claiming to be support. All official assistance happens through support tickets inside the server.
</Warning>

## Ticket categories

| Category               | For                                    |
| ---------------------- | -------------------------------------- |
| **Trading issues**     | Order placement or execution problems  |
| **Payout issues**      | Withdrawal or settlement problems      |
| **Wallet problems**    | Funding, balance, or wallet errors     |
| **Dashboard bugs**     | UI errors or incorrect data            |
| **Risk engine issues** | Incorrect drawdown or rule calculations |
| **Security reports**   | Vulnerabilities or exploit attempts    |

## What to include

Describe the issue as fully as you can:

* What happened and what you expected
* Any trade IDs or timestamps
* Screenshots or recordings
* Your wallet address or account identifier
* The steps to reproduce it

## Rewards

| Reward                  | Description                          |
| ----------------------- | ------------------------------------ |
| **DojiPoints**          | Platform points for valid submissions |
| **Community rewards**   | Recognition across the community     |
| **Early access**        | Priority access to new features      |
| **Ecosystem incentives**| Additional rewards during active campaigns |

Higher-severity reports may qualify for larger rewards.

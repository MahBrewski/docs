If you find an issue in the platform, report it through the official support path with enough detail for reproduction.

## How to report a bug

1. Join the official DojiFunded Discord server.
2. Complete server verification so you can access support channels.
3. Open a support ticket in the relevant support or ticket channel.
4. Choose the category that best matches the issue.
5. Add enough detail for the team to reproduce the problem.

## Ticket categories

Common categories include:

- trading issues
- payout issues
- wallet problems
- dashboard bugs
- risk engine issues
- security reports

## What to include

Include:

- the page or product area where the issue happened
- the account type or account state involved
- the market or execution venue involved
- what you expected to happen
- what actually happened
- any relevant wallet, transaction, or payout context
- screenshots or screen recordings when available

## High-priority issue types

Report these issues with as much detail as possible:

- order placement problems
- incorrect account state or drawdown calculations
- payout issues
- wallet funding problems
- broken navigation or blocked workflows

## Security note

Never trust unsolicited direct messages from users claiming to be support staff.

Do not:

- share wallet keys or passwords
- trust unsolicited DMs
- send funds to anyone claiming to be support

Official support is handled through verified support tickets.

## Rewards

Valid bug reports may be eligible for rewards such as:

- DojiPoints
- community rewards
- early feature access
- campaign-based ecosystem incentives

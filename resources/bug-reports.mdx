If you find an issue in the platform, send a report with enough context for reproduction.

## What to include

Include:

- the page or product area where the issue happened
- the account type or account state involved
- the market or execution venue involved
- what you expected to happen
- what actually happened
- any relevant wallet, transaction, or payout context
- screenshots or screen recordings when available

## High-priority issue types

Report these issues with as much detail as possible:

- order placement problems
- incorrect account state or drawdown calculations
- payout issues
- wallet funding problems
- broken navigation or blocked workflows

## Contact path

Use the support channel listed in the docs site navigation or footer unless a separate bug intake flow is added later.

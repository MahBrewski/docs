DojiFunded offers four account types with funding from **$1K to $100K**, each suited to a different trading style and risk profile. Across all of them, drawdown is static and measured on realised balance.

## What differs between account types

| Rule                        | Instant Funding *(soon)* | 1-Step            | 2-Step Classic     | 2-Step Elite       |
| --------------------------- | ------------------------ | ----------------- | ------------------ | ------------------ |
| **Funding model**           | Instant funding          | Single evaluation | Two-phase evaluation | Two-phase evaluation |
| **Profit target**          | None                     | 10%               | 5%, then 10%       | 5%, then 10%       |
| **First / min withdrawal** | First after 5% profit    | ≥ 1% of size      | ≥ 1% of size       | ≥ 1% of size       |
| **Max drawdown**           | 5% static                | 6% static         | 6% static          | 8% static          |
| **Daily drawdown**         | None                     | 3%                | 3%                 | 5%                 |

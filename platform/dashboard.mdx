## Account overview

Each account shows its key metrics live. Equity displays in real time including open positions, and drawdown limits are measured on **HWM basis**, so open positions count the moment they move.

| Metric                    | What it shows                                |
| ------------------------- | -------------------------------------------- |
| **Current equity**        | Account value now, including open positions  |
| **Remaining daily loss**  | Portion of today's daily loss allowance left |
| **Remaining max drawdown**| Distance from your account value to the floor |
| **Profit target progress**| How close you are to passing                 |
| **Payout eligibility**    | Whether the account qualifies for a withdrawal |
| **Account status**        | Phase, plan, size, and trading status        |

## Performance analytics

View your history across **1 day, 1 week, 1 month, and all time**.

| View               | What it plots                                |
| ------------------ | -------------------------------------------- |
| **Equity**         | Account value over time, including open positions |
| **Balance**        | Closed value only, excluding open positions  |
| **Profit target**  | A line marking your target threshold         |
| **Daily drawdown** | Daily loss usage over time                   |
| **Maximum drawdown**| Max drawdown usage over time                |
| **Calendar**       | Day-by-day performance                       |

## Trading statistics

| Metric                    | Description                     |
| ------------------------- | ------------------------------- |
| **Total trades**          | Completed trades                |
| **Win rate**              | Share of profitable trades      |
| **Total volume**          | Total trading volume            |
| **Average trade size**    | Typical position size per trade |
| **Profit target remaining**| Amount still required to pass   |
| **Current payout**        | Currently eligible payout amount |

## Open positions and history

Live positions show size, entry price, current price, unrealized PnL, return on equity, and duration. Closed trades are stored in full detail, including realised PnL, timestamps, and verification records.

## Risk monitoring

Tracked live. Drawdown limits are measured on HWM basis while the rest updates with the market.

| Metric               | What it shows                          |
| -------------------- | -------------------------------------- |
| **Drawdown usage**   | How close your account value is to the limit |
| **Margin utilization**| Margin used across open positions      |
| **Active exposure**  | Total open position exposure           |
| **Breach proximity** | How close the account is to failing    |

## Payout tracking

Monitor your eligibility, withdrawal history, on-chain settlement records, and progress toward your next payout. All payouts settle to your embedded wallet.

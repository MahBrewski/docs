The dashboard is the central hub for managing assessments, funded accounts, payouts, and trading analytics.

Real-time account data is continuously updated to provide a live view of account performance, drawdown usage, open positions, and payout eligibility.

The dashboard includes equity tracking, account analytics, risk monitoring, payout history, and performance insights across all supported execution venues.

## Account Overview

Each account includes a live overview of:

- current equity
- remaining daily loss allowance
- remaining maximum drawdown
- profit target progress
- payout eligibility

Drawdown calculations are equity-based and include floating PnL from open positions.

The dashboard also displays account phase, active plan, account size, and current trading status.

## Performance Analytics

Performance data can be viewed across:

- 1D
- 1W
- 1M
- All Time

Charts display:

- Equity
- Balance
- Profit target
- Daily drawdown
- Maximum drawdown

Trading activity is also available in calendar format for reviewing day-by-day performance.

## Trading Statistics

Each account includes lifetime trading statistics and performance metrics.

| Metric                  | Description                                   |
| :---------------------: | :-------------------------------------------: |
| Total Trades            | Total completed trades                        |
| Win Rate                | Percentage of profitable trades               |
| Total Volume            | Total trading volume                          |
| Average Trade Size      | Average position size per trade               |
| Profit Target Remaining | Remaining amount required to pass             |
| Current Payout          | Current eligible payout amount                |

Statistics update automatically as positions are opened and closed.

## Open Positions & Trade History

Active positions display live market data including:

- position size
- entry price
- current price
- unrealized PnL
- ROE percentage
- trade duration

Completed trades are stored in the position history section with full execution details, realized PnL, timestamps, and trade verification records.

## Risk Monitoring

The dashboard continuously tracks drawdown usage, margin utilization, active exposure, and breach proximity in real time.

All risk calculations are based on live equity and update dynamically as market conditions change.

## Payout Tracking

Eligible funded traders can monitor payout availability directly from the dashboard.

The payout section displays:

- current payout eligibility
- withdrawal history
- settlement records
- payout progress across funded accounts

All payouts are processed directly to the user's embedded wallet.
